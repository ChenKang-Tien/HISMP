三大評估儲存規則 (結構化索引與備註)
----------------------------------------

原則：選項存數字索引，備註文字附加於該欄位之後，以逗號分隔。

1. vascular_access_type (血管通路種類):
   格式: "種類索引" + "," + "Permcath 長度 (若為 Permcath)"
   - AVF:0, AVG:1, Permcath:2, D/L:3
   - 預設值: "0"

2. vascular_access_location (血管通路位置):
   格式: "LR_Idx,Center_Idx"
   - L/R 分組索引: L't:0, R't:1
   - 中心/導管分組索引: SCVC:2, JVC:3, FVC:4
   - 預設值: "0,2" (L't, SCVC)

3. vascular_access (血管通路評估):
   格式: "索引1,索引2..." + "," + "備註文字"
   - 正常:0, 紅:1, 腫:2, 熱:3, 痛:4, 滲血:5
   - 預設值: "0"

4. Permcath 長度:
   - 已併入 vascular_access_type 欄位。

5. consciousness (意識狀態):
   格式: "索引" + "," + "備註文字"
   - 清醒:0, 嗜睡:1, 木僵:2, 半昏迷:3, 昏迷:4, 失智:5
   - 預設值: "0"

6. skin (皮膚完整性):
   格式: "索引" + "," + "部位" + "," + "大小" + "," + "備註文字"
   - 完整:0, 有傷口（含水泡）:1
   - 預設值: "0"
